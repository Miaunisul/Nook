
# System Requirements

This directory contains the functional, non-functional, security, and acceptance requirements for Nook.

## Main document

- `system-requirements.md` — complete system requirements, security requirements, and acceptance criteria.

## Requirement categories

- **Functional requirements (RF):** features and expected system behavior.
- **Non-functional requirements (RNF):** quality attributes, performance, reliability, and usability.
- **Security requirements (SEG):** privacy, authentication, authorization, and data protection.
- **Acceptance criteria (CA):** verifiable conditions used to validate implementation.

## Maintenance

Requirement identifiers should remain stable so that implementation tasks, tests, and documentation can reference them consistently.

Changes to requirements must be reviewed against the business rules, architecture, database model, and implementation plan.
